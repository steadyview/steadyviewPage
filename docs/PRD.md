# STEADYVIEW 기업 홈페이지 PRD (Product Requirements Document)

## 1. 개요 / 문서 정보

| 항목 | 내용 |
|---|---|
| 프로젝트명 | STEADYVIEW 기업 홈페이지 |
| 문서 버전 | v1.0 |
| 작성일 | 2026-07-16 |
| 프로젝트 목적 | 2D/3D 머신비전 및 산업용 X-ray 검사장비 소개 및 견적문의 전환 |
| 기술 스택 | Next.js (App Router) + TypeScript |
| 배포 | Vercel |
| 배포 URL | (추후 확정) |

### 1.1 회사 개요
STEADYVIEW는 **2D 머신비전, 3D 머신비전, 산업용 X-ray 검사장비**를 개발·공급하는 B2B 기업이다. 주요 적용 분야는 2차전지 검사, 반도체 검사, 산업용 X-ray 비파괴 검사이다.

### 1.2 대상 사용자 (Target Users)
- **국내외 제조 고객**: 2차전지, 반도체, 전자부품 제조사의 품질·생산 담당자
- **해외 바이어 / 수출 파트너**: 영어권·중화권 잠재 고객
- **투자자 / IR 이해관계자**: 재무·공시 자료 열람자
- **채용·협력 문의자**

## 4. 페이지별 상세 요구사항

각 페이지는 **목적 / 주요 섹션 / 콘텐츠 / 기능 / 컴포넌트** 관점으로 정의한다.

### 4.1 메인 페이지 (`/`)

- **목적**: 회사 첫인상 전달, 핵심 사업 영역 시각화, 주요 페이지로 유도
- **주요 섹션**
  1. **히어로 이미지 슬라이더 (필수)**
     - 이미지 3장 자동 순환 + 수동 조작(화살표/인디케이터)
     - 슬라이드 1: **2차전지 검사**
     - 슬라이드 2: **산업용 X-ray 검사**
     - 슬라이드 3: **3D 반도체 검사**
     - 각 슬라이드에 제목·짧은 설명·해당 제품 페이지 링크(CTA) 오버레이
  2. **간단한 회사 소개**: 한 문단 소개 + 핵심 키워드(정밀 검사, 머신비전, X-ray)
  3. **제품 바로가기**: 2D / 3D / X-ray 3개 카드
  4. **문의 CTA**: "견적문의 하기" 버튼 → `/contact`
- **기능**: 자동재생/일시정지, 반응형(모바일 스와이프), 이미지 지연 로딩
- **컴포넌트**: `HeroSlider`, `IntroSection`, `ProductCards`, `CtaBanner`

### 4.2 회사소개 (`/about`)

#### 4.2.1 STEADYVIEW 소개 (`/about`)
- **목적**: 회사 정체성·역량·연혁 전달
- **콘텐츠**: 회사 개요, 비전/미션, 핵심 역량(2D/3D/X-ray 기술), 주요 연혁(타임라인), (선택) 주요 고객/인증
- **컴포넌트**: `CompanyOverview`, `VisionSection`, `HistoryTimeline`

#### 4.2.2 CEO 인사말 (`/about/ceo`)
- **목적**: 경영 철학·신뢰 전달
- **콘텐츠**: CEO 사진, 인사말 메시지, 서명/직함
- **컴포넌트**: `CeoGreeting`

#### 4.2.3 찾아오시는 길 (`/about/location`)
- **목적**: 위치·연락 정보 제공
- **콘텐츠**: 지도(임베드), 주소, 대표 전화/팩스/이메일, 대중교통·자가용 안내
- **기능**: 지도 임베드(카카오/네이버/구글 맵 중 선택), 주소 복사(선택)
- **컴포넌트**: `MapEmbed`, `ContactInfo`

### 4.3 제품 (`/products`)

공통 상세 템플릿: **제품 개요 / 주요 특징 / 사양표 / 적용 분야 / 이미지·갤러리 / 문의 CTA**

#### 4.3.1 2D 비전 (`/products/2d-vision`)
- 2D 머신비전 검사 솔루션 소개, 특징, 사양, 적용 분야(2차전지·전자부품 등)

#### 4.3.2 3D 비전 (`/products/3d-vision`)
- 3D 머신비전 검사 솔루션 소개, 특징, 사양, 적용 분야(3D 반도체 검사 등)

#### 4.3.3 X-ray (`/products/xray`)
- 산업용 X-ray 비파괴 검사 장비 소개, 특징, 사양, 적용 분야(2차전지·반도체 내부 검사 등)

- **컴포넌트**: `ProductHero`, `ProductFeatures`, `SpecTable`, `ApplicationList`, `ProductGallery`

### 4.4 IR (`/ir`)

#### 4.4.1 IR DATA (`/ir`)
- **목적**: 투자자·이해관계자에게 재무·공시 자료 제공
- **콘텐츠**: IR 자료 목록(제목·구분·게시일·PDF 다운로드), 공시/재무 자료
- **기능**: 자료 리스트, PDF 다운로드 링크, (선택) 카테고리 필터
- **컴포넌트**: `IrList`, `IrDownloadItem`
- 비고: 정적 콘텐츠로 관리(자료 추가 시 파일 등록 후 재배포)

### 4.5 견적문의 (`/contact`)

- **목적**: 견적/문의 리드 확보
- **입력 폼 필드**
  | 필드 | 필수 | 유형 |
  |---|---|---|
  | 회사명 | 필수 | text |
  | 담당자명 | 필수 | text |
  | 연락처 | 필수 | tel |
  | 이메일 | 필수 | email |
  | 관심 제품 | 필수 | select (2D 비전 / 3D 비전 / X-ray / 기타) |
  | 문의 내용 | 필수 | textarea |
  | 개인정보 수집·이용 동의 | 필수 | checkbox |
- **기능**
  - 클라이언트/서버 유효성 검사
  - 제출 시 **회사 대표 이메일로 문의 내용 전송** (DB 저장 없음)
  - 스팸 방지(허니팟 또는 reCAPTCHA — 선택)
  - 제출 성공/실패 피드백, 중복 제출 방지
- **컴포넌트**: `ContactForm`, `FormField`, `PrivacyConsent`

- 지원 언어: **ko(기본) / en / zh**
- 모든 UI 텍스트·메뉴·폼 라벨·에러 메시지 번역
- 언어 전환 UX: 헤더 언어 선택기, 선택 언어 유지(쿠키/URL)

## 7. 비기능 요구사항 (NFR)

- **반응형**: 모바일 / 태블릿 / 데스크톱 브레이크포인트 대응
- **성능**: 이미지 최적화(`next/image`), LCP ≤ 2.5s, 코드 스플리팅, 폰트 최적화
- **SEO**: 페이지별 메타 태그, Open Graph, `sitemap.xml`, `robots.txt`, 구조화 데이터(선택)
- **접근성(a11y)**: 시맨틱 마크업, 이미지 alt, 키보드 내비게이션, 명도 대비, 슬라이더 ARIA
- **브라우저 지원**: 최신 Chrome/Edge/Safari/Firefox 및 모바일 브라우저
- **보안**: 폼 입력 검증/새니타이즈, 이메일 API 키 서버 측 보관, 스팸 방지

## 8. 기술 스택 및 아키텍처

### 8.1 기술 스택
| 영역 | 선택(권장) |
|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript |
| 스타일링 | Tailwind CSS (권장) |
| 다국어 | next-intl (또는 next 내장 i18n 라우팅) |
| 이미지 | next/image |
| 슬라이더 | Swiper 또는 Embla Carousel |
| 폼 | react-hook-form + zod |
| 이메일 전송 | Resend (또는 Nodemailer) + Route Handler(`app/api/contact`) |
| 지도 | 카카오맵/네이버맵/Google Maps 임베드 |

### 8.2 제안 폴더 구조
```
app/
  [locale]/
    layout.tsx
    page.tsx                 # 메인
    about/
      page.tsx               # 소개
      ceo/page.tsx           # CEO 인사말
      location/page.tsx      # 찾아오시는 길
    products/
      2d-vision/page.tsx
      3d-vision/page.tsx
      xray/page.tsx
    ir/page.tsx
    contact/page.tsx
  api/
    contact/route.ts         # 견적문의 이메일 전송
components/                  # 공통·페이지 컴포넌트
content/                     # 정적 콘텐츠(제품 사양, 연혁, IR 목록 등)
messages/                    # ko.json / en.json / zh.json (i18n 번역)
public/                      # 이미지, IR PDF, 로고
```

### 8.3 정적 콘텐츠 관리 방식
- 제품 사양·연혁·IR 목록 등은 `content/`의 JSON/TS 파일 또는 마크다운으로 관리
- IR PDF·이미지는 `public/`에 배치
- **콘텐츠 수정 = 파일 수정 후 Git push → Vercel 자동 재배포** (별도 관리자 CMS 없음)
